# Contributing to Remark42

## Issue or Discussion?

[Issues](https://github.com/umputun/remark42/issues) are for bugs in Remark42 and for concrete changes to it. Everything else belongs in [Discussions](https://github.com/umputun/remark42/discussions):

- a question about how to do something, in **Q&A**;
- help with an installation that does not work (reverse proxy, OAuth provider, SMTP, Docker), also in **Q&A**. If you are not sure whether the cause is a bug or your configuration, start there;
- an idea that needs talking through before anyone could act on it, in **Ideas**.

## Before opening a pull request

Fixes for bugs, documentation and translations are welcome as pull requests straight away.

Other changes (a feature, a new option or provider, a dependency or tooling change, a refactoring) need a maintainer's agreement first, so that nobody spends time on a change that will not be merged. Open an issue that describes what you would like to change and why, or find the existing one, and say there that you are willing to make the pull request. Open the pull request once a maintainer has agreed.

Development setup is described in the [backend](https://remark42.com/docs/contributing/backend/), [frontend](https://remark42.com/docs/contributing/frontend/) and [translations](https://remark42.com/docs/contributing/translations/) guides.
