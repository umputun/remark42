How to use Markdown in Remark42

Markdown is a lightweight and easy-to-use syntax for styling Remark42 comments. You control the display of the comment, formatting words as bold or italic, adding images, and creating lists are just a few of the things we can do with Markdown.

Headers & Quotes

Sometimes it's useful to have different levels of headings to structure your comments. Start a line with a # and a space to create a heading, such as ## Details.

You can use one # all the way up to ###### six for different heading sizes.

If you’d like to quote someone, use the > character before the line

Text

It's very easy to make some words bold: surround them with double asterisks ** and other words italic: surround them with one asterisk *.

You can even link to Google! using this syntax:
[link to Google!](https://google.com)

A web address starting with https:// or http://, such as https://remark42.com, becomes a link by itself.

To strike words through, surround them with two tildes: ~~like this~~.

A line break within a paragraph stays a line break; an empty line starts a new paragraph.

Lists

If you want numbered lists:

1. One
2. Two
3. Three
   1. Item 3.1
   2. Item 3.2

If you want bullet point

* Item 1
* Item 2
  * Item 2a
  * Item 2b

Images

If you want to embed images, this is how you do it:

![Image of my cat](https://example.com/cat.jpg)

Code

You can create code span by wrapping text in backtick quotes: `your code`

For a block of code, put it between two lines of three backticks. Name the language after the first three to highlight its syntax: 

```go
func main() {}
```

Tables

You can create tables by assembling a list of words and dividing them with hyphens - (for the first row), and then separating each column with a pipe |: 

|First Header | Second Header|
|------------ | -------------|
|Content from cell 1 | Content from cell 2|
|Content in the first column | Content in the second column|
